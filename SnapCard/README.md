## 🧩 Overview

**SnapCard v0** is a browser-based tool that allows users to fill out a simple form and instantly generate a styled profile card. Each card displays a profile picture (via URL), name, profession, and a short bio — all rendered dynamically using the DOM.

No page reloads. No libraries. Just clean, working JavaScript.

---

## 🚧 Version Notice

> **SnapCard v0 is an early-stage trial release.**

This version (`v0`) was built as a learning and experimentation project. It intentionally keeps styling minimal and straightforward — the focus is on **functionality over polish**. A more feature-rich and visually refined version may follow based on feedback and interest.

**What to expect in v0:**
- ✅ Core card generation works reliably
- ✅ Fully responsive across screen sizes
- ⚠️ No advanced or complex styling
- ⚠️ No backend, no persistence — cards reset on page refresh
- ⚠️ Feature set is intentionally limited

If you find it useful or interesting, consider **leaving a ⭐ star** on the repo — it really helps and motivates further development!

## ✨ Features

- 📷 Profile picture loaded via any browser-accessible image URL
- 🧾 Dynamic card creation with name, profession, and bio
- ✅ Input validation — alerts user if any field is left empty
- 🔄 Auto-resets the form after each card is created
- 🃏 Supports generating multiple cards in a single session
- 📱 Responsive — works across desktop and mobile browsers

## 🛠️ Getting Started

### Prerequisites

All you need is a modern web browser. No installations or dependencies required.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/SnapCard.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd SnapCard
   ```

3. **Open `index.html` in your browser:**
   ```bash
   open index.html
   # or simply double-click the file
   ```

---

## 📖 Usage

1. Enter a **publicly accessible image URL** for the profile picture.
2. Fill in the **Name**, **Profession**, and **Bio** fields.
3. Click **Submit** to generate your profile card.
4. Repeat to generate as many cards as you like — they stack below the form.

> ⚠️ All fields are required. An alert will appear if any field is left blank.
