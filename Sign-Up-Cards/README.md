# Sign Up Cards 🪪

A mini frontend project featuring sign-in card UI clones of **Google Pay** and **Pinterest** — built as a CSS practice exercise focusing on layout, form styling, and visual consistency.

---

## 🔍 About

This project recreates the sign-in page aesthetic of two popular platforms side by side. It's a hands-on CSS exercise — no frameworks, no libraries, just vanilla HTML and CSS doing the work.

---

## 🛠️ Built With

- **HTML5** — semantic structure and form elements
- **CSS3** — layout, card styling, form inputs, and responsiveness
- **Google Fonts** — Poppins for clean, modern typography

---

## ✨ Features

- 🎨 Side-by-side sign-in cards for Google Pay and Pinterest
- 📋 Form inputs with email/phone and password fields
- 🔗 Functional links for "Forgot Password?" and "Create Account"
- 🖋️ Consistent typography using Poppins font family
- 🧼 Clean, minimal UI that closely mirrors the real thing

## 🚀 Getting Started

No setup needed. Just clone the repo and open `index.html` in your browser.

```bash

cd sign-up-cards
```

Then open `index.html` — done.
