# Activity Status Tracker v1.0 🪪

A clean, interactive profile card built with HTML, CSS, and vanilla JavaScript. This was a practice project focused on DOM manipulation and click event handling in JS.

---

## 📸 Preview

> A dark-themed card featuring a profile picture, username, bio, and a live status toggle button.

---

## ✨ Features

- **Status Toggle** — Click the "Active" button to switch between Active/Inactive states, with color feedback on both the button and the status indicator
- **Responsive Design** — Adapts layout for mobile portrait screens and smaller viewports
- **Custom Fonts** — Uses *Cormorant Garamond* and *Courier Prime* via Google Fonts for a distinct look
- **Minimal Vanilla JS** — No libraries, just a simple `onclick` event driving all interactivity

---

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox, Media Queries)
- JavaScript (DOM manipulation, click events)

---

## 🚀 Getting Started

1. Clone the repo
   ```bash
   git clone https://github.com/your-username/activity-status-tracker.git
   ```
2. Open `index.html` in your browser — that's it, no build step needed.

> ⚠️ Make sure the profile image file is in the same directory as `index.html`, or update the `src` path in the `<img>` tag accordingly.

## 🧠 What I Practiced

- Handling click events with `onclick` and `document.querySelector`
- Conditionally updating `textContent` and inline styles via JS
- Writing responsive CSS with `@media` queries for different screen sizes
- Layering CSS positioning (`relative`, `left`, `bottom`) for fine-tuned layout control

---

## 📌 Notes

This is a beginner-to-intermediate practice project, not a production component. The goal was to get comfortable with event-driven UI updates before moving on to more complex JS patterns.
